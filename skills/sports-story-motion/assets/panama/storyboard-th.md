# คลองปานามา — ชุดเรื่องสาธิต

สถานะ: บทพร้อมสร้างเสียง แต่ยังไม่มีเสียงจาก Google AI Studio และยังไม่ได้จัดคิวซับจากเสียงจริง
ไทม์ไลน์ 26 วินาทีที่ให้เป็น animation test เท่านั้น ต้องแก้คิวจากไฟล์เสียงที่ใช้จริงก่อน final

## ชื่อโพสต์ 5 แบบ

1. ทำไมเรือยักษ์ต้องถูกยกขึ้นกลางคลองปานามา?
2. เรือข้ามมหาสมุทรได้อย่างไร เมื่อทางผ่านอยู่สูงกว่า?
3. ประตูน้ำคลองปานามา ยกเรือยักษ์ได้อย่างไร?
4. ตามเรือลำเดียว ไปดูลิฟต์น้ำแห่งคลองปานามา
5. น้ำยกเรือได้อย่างไร? คำตอบอยู่ที่คลองปานามา

เลือกข้อ 1 เพราะสั้น เป็นคำถามตรงกับคำตอบ และไม่มีตัวเลขที่ต้องใช้ดึงความสนใจ
หัวข้อบนจอ: “ทำไมเรือยักษ์ / ต้องถูกยกขึ้น?”

## Hook 3 แบบพร้อมภาพ

- คำถาม: “ทำไมเรือยักษ์ลำนี้ ต้องถูกยกขึ้นก่อนข้ามคลองปานามา?”
  ภาพ: เรืออยู่ในห้องประตูน้ำ น้ำและเรือเริ่มสูงขึ้น กล้องตัดไปบอกตำแหน่งปานามา
- เหตุการณ์น่าประหลาดใจ (เลือกใช้): “เรือยักษ์ลำนี้ กำลังถูกยกขึ้นด้วยน้ำ ทำไมต้องยก?”
  ภาพ: ภาพตัดขวางห้องประตูน้ำ น้ำไหลเข้า เรือที่ลอยอยู่สูงตาม ให้ชื่อขึ้นทันที
- สมมติ: “ลองสมมติว่าเรือจะข้ามปานามา แต่ทางข้างหน้าอยู่สูงกว่าระดับทะเล จะไปต่ออย่างไร?”
  ภาพ: ขึ้นคำว่า “สมมติ” และใช้ลูกศรไปยังทะเลสาบ ไม่แสดงเป็นเหตุการณ์ข่าวที่เกิดขึ้นจริง

คำถามหลัก: ทำไมต้องยกเรือขึ้น และระบบทำได้อย่างไร?
คำตอบก่อนจบ: เส้นทางผ่านทะเลสาบกาตุนที่สูงกว่าระดับทะเล ห้องประตูน้ำเปลี่ยนระดับน้ำ เรือจึงลอยสูงหรือต่ำตาม

## ลำดับภาพ

| ช่วงทดสอบภาพ (ยังไม่ใช่คิวเสียงจริง) | ภาพและหน้าที่ |
|---|---|
| 0–2.4 | Hook เรือถูกยกด้วยระดับน้ำใน diagram; แสดงหัวข้อทันที |
| 2.5–6 | แผนที่มุมกว้าง → ประเทศส้ม → ธงปานามา → พักให้เห็นตำแหน่ง |
| 6–13 | ซูมต่อเนื่องและเอียงสู่ mesh DEM จริง; ธงและป้ายใช้พิกัด WGS84 |
| 9–15 | ลูกศรค่อย ๆ วาดและเรือลำเดิมเคลื่อนตามเส้นทางประกอบคำอธิบาย |
| 15–23 | ภาพกลไกประตูน้ำ น้ำเข้า เรือสูงตาม; บอกว่าเป็นภาพอธิบาย |
| 23–26 | กลับแผนที่และตอบคำถามเปิดเรื่อง |

ใช้แม่น้ำ ภูเขา ชายฝั่งจากแผนที่และ DEM จริง ภาพกลไกเป็น infographic ไม่ใช่ภาพ terrain หรือมาตราส่วนวิศวกรรม
ไม่ใส่โลโก้ ชื่อช่อง หรือ CTA ไม่เพิ่ม watermark โดยไม่มีคำสั่ง
ไม่มีซับ SRT ที่กะเวลาจากจำนวนคำ; ให้ทำจากเสียงจริง

## สิ่งที่ยังต้องตรวจจากผู้ใช้/สภาพแวดล้อมจริง

ยังไม่ได้ดูคลิปอ้างอิงทั้งสองลิงก์ ต้องมีภาพนิ่งหรือคลิปช่วงเปิด แผนที่ซูม และไอคอน ก่อนออกแบบรายละเอียดให้ใกล้ต้นฉบับ
สร้างเสียงจากบัญชี Google AI Studio ที่ผู้ใช้ลงชื่อเข้าใช้ เลือก model/voice จากรายการจริง ฟังและแก้คำอ่าน “ปานามา”, “กาตุน”
ความยาวอาจเปลี่ยนหลังฟังเสียงจริง ให้คิวตามเสียงจริงและรักษาช่วงพักภาพ
